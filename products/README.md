## 폴더 구조

제품 하나당 폴더 하나입니다. 앞의 3종은 시스템의 **제품 지식 매핑(KB) 화면**과 1:1로 대응하고,
뒤의 4종은 제안 현장에서 반복 요구받는 **제안 대응 문서**입니다.

```
products/
├── README.md                 ← 이 파일 (제품 목록 인덱스)
├── 작성가이드.md              ← 제품 담당자 작성 가이드
├── _양식/                     ← 새 제품 폴더 양식 (통째로 복사해서 사용)
│   ├── README.md             ← 제품 문서 양식
│   ├── slides.md             ← 제안 슬라이드 인덱스 양식
│   ├── images/README.md      ← 화면 캡쳐 파일명·삽입 규칙
│   ├── 소개서.md              ← 제품 소개 양식
│   ├── 매뉴얼.md              ← 매뉴얼 안내 양식
│   ├── 사이징.md              ← 서버 사이징·이중화 양식
│   └── 제안대응.md            ← 수용 여부·M/M 산정 양식
└── <제품명 한글>/
    ├── README.md             ← 「기능」 제품 설명·기능 계층        ┐
    ├── slides.md             ← 「슬라이드」 요구사항 ↔ 대응 문장    │ KB(자동 생성)가 읽음
    ├── images/               ← 「이미지」 제품 화면 캡쳐 png        ┘
    ├── 소개서.md              ← 소개서·리플릿 위치와 소개 논리      ┐
    ├── 매뉴얼.md              ← 매뉴얼 목록·제공 범위·기술지원       │ 사람이 찾아 씀
    ├── 사이징.md              ← 데이터 용량별 서버 스펙·이중화       │ (제안 대응 문서)
    └── 제안대응.md            ← 요구사항 수용 여부·M/M·일정 산정    ┘
```

> ⚠️ **공개(public) 저장소입니다.** 제안서 원본 pptx·고객 제안 문안·계약 금액·고객 실데이터 화면·
> 소개서/매뉴얼 원본 파일은 올리지 마세요. 원본은 `slides.md`·`소개서.md`·`매뉴얼.md` 에 **위치만** 적습니다.

## 작성 규칙 (요약)

- 폴더명: 제품명을 한글로 (예: `와이즈인텔리전스/`, `와이즈DQ/`)
- 제품 설명은 폴더 안 `README.md` 에 작성 — 기능은 `### 대분류 → #### 중분류 → - **소분류**: 설명` 계층
- 각 문서 하단 **"제안서 작성 시 강조 포인트"** 섹션이 제안서 생성 시 우선 반영됨
- 인증·스펙 변경 시 해당 문서와 루트 `company_profile.json` 을 함께 업데이트
- 제안 대응 문서 4종은 확인 못 한 값을 빈칸으로 두지 말고 `미보유`·`별도 협의`·`확인 중` 으로 상태 표기
- 새 제품 추가 시 `_양식/` 폴더 복사 → 작성 → 이 README 목록·작성 현황에도 추가
- 상세는 [작성가이드.md](./작성가이드.md)
