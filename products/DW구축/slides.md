## 읽는 법

| 열 | 의미 |
|----|------|
| 요구사항명 | RFP 요구사항 문장과 매칭되는 이름. **pptx 파일명이 곧 요구사항명**입니다. |

| 원본 위치 | 원본 pptx 경로 + 슬라이드 장수 |

## 작성 요령

- **요구사항명은 RFP 표현으로**: "플랫폼 데이터 수집 방법", "모델 서빙 방법"처럼
  실제 요구사항정의서에 나오는 말로 짓습니다. 이 이름이 검색 키가 됩니다.
- **한 슬라이드 = 한 요구사항**: 여러 요구사항을 한 장에 몰아넣으면 매칭 정확도가 떨어집니다.
- **고객사·사업명·특정 도메인 용어는 일반화**: "○○공사 배관 경로" → "설비 경로".
- 원본 pptx 를 사내 담당자에게 전달하면 `ppt_template/products/<제품영문명>/` 에 배치되고,
  KB 동기화 시 자동으로 시드(콘텐츠 JSON)로 변환됩니다.
